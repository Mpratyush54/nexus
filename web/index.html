no token

Token is kept in localStorage and sent as Authorization: Bearer <token> on every REST call; the dashboard socket appends ?token= automatically (the WS endpoint also accepts it — browsers cannot set WS headers). HTTP 401 or an auth error frame drops the token and asks for re-login. API/WS default to same-origin (wss on https); override only for cross-host dev.
